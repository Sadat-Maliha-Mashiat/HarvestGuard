# HarvestGuard 🌾
Your trusted partner in crop protection and growth. Smart farm management, weather & map; crop health alerts — all in one place.

# About
HarvestGuard is a HackFest project developed at East Delta University under the initiative of the East Delta University Computer Club and presented by Byte City. It is a Bangla-first, farmer-centric web application designed to reduce post-harvest food loss through weather-aware risk insights, offline-capable data handling, and localized decision support.

# Features
- Storytelling landing page
- Farmer & crop management (offline support)
- Hyper-local weather integration
- Risk alerts & local risk visualization

# Tech Stack
- Frontend: HTML, CSS, JavaScript, React.js
- Storage: LocalStorage (offline-first)
- APIs: Free Weather API
- UI: Mobile-first, Bangla-first
